# Go CRUD Application with Docker and Minikube

This is a simple CRUD (Create, Read, Update, Delete) REST API built in **Go**. The application uses **Docker** for containerization and is deployed locally using **Minikube**.

---

## 🧰 Tech Stack

- **Go (Golang)** – REST API
- **Docker** – Containerization
- **Minikube** – Local Kubernetes cluster
- **kubectl** – Kubernetes CLI
